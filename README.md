# DNA Sequence Analyzer

## Description
A simple Python program that analyzes DNA sequences from a FASTA file.

## Features
- Reads DNA sequences from a FASTA file.
- Calculates sequence length.
- Calculates GC percentage.
- Translates DNA codons into amino acid sequences.
- Saves the results to a CSV file.
- Displays the results in the terminal.


## Input
The input file is `sequences.fasta`, which contains five DNA sequences.

## Output
The program creates `results.csv` with the following columns:
- id
- length
- gc_percent
- AA Sequence
